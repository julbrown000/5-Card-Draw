# 5-Card-Draw
A simple 5 card draw poker game made for the CS 193 Final Project.
The goal is to create a Java program which creates a network allowing at least 2 people to play a game of 5 card draw.

MVP Scope: 
Network allowing communication with opponent.
Card Class allowing for the creation of Card Objects to be used throughout the program.
Program that decides strength of card hands and determines a winner.
Basic "betting" based on fake currency, adding some stakes to the game.

Future Plans:
GUI elements rather than only using the terminal.
Images for cards to provide visuals and make the game more engaging.
Basic chatting features between players.
Allow for any amount of people to play.
